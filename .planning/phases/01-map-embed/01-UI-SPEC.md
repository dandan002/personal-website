## Layout

| Property | Value | Source |
|----------|-------|--------|
| Layout pattern | Flex row, wrap on mobile | Inline `style` prop; `display: "flex", flexWrap: "wrap", gap: "2rem"` |
| Desktop column split | ~50/50 — left col `flex: 1`, right col fixed 350px | D-02 from CONTEXT.md |
| Mobile behavior | Single column, stacks text above map | `flexWrap: "wrap"` collapses to column when map hits full width |
| Map size (desktop) | 350px × 350px (square) | D-04 from CONTEXT.md |
| Map size (mobile) | 100% width, height auto (aspect-ratio 1 / 1) | MAP-02 responsive requirement |
| Map zoom level | 13, centered on Manhattan, NYC | D-05 from CONTEXT.md |
| ScrollReveal | Wrap entire two-column block inside existing `<ScrollReveal>` | CONTEXT.md code_context |

**Desktop column widths (inline style):**
- Left column: `style={{ flex: 1, minWidth: "240px" }}`
- Right column: `style={{ width: "350px", flexShrink: 0 }}`

On screens narrower than ~600px, `flexWrap: "wrap"` causes both columns to go full-width, stacking text above map. The map column uses `width: "100%"` override via `minWidth: "100%"` at that breakpoint — implement with a CSS media query in `globals.css` or via the `style` prop using `max-width` on the right column.

## Map Container

The iframe is wrapped in a `<div>` styled to match the existing card vocabulary.

| Property | Value | Rationale |
|----------|-------|-----------|
| Background | `var(--color-surface)` = `#141410` | `.project-card` default |
| Border | `1px solid var(--color-border)` = `1px solid #222220` | `.project-card` default |
| Border radius | `2px` | Matches scrollbar thumb radius — only non-zero radius in the project |
| Overflow | `hidden` | Clips iframe corners to match border-radius |
| Hover border | `var(--color-accent)` = `#b8845a` | Matches `.project-card:hover` |
| Hover background | `var(--color-accent-glow)` = `rgba(184, 132, 90, 0.08)` | Matches `.project-card:hover` |
| CSS class | `.project-card` applied to container `<div>` | Reuses existing class from `globals.css:141` |
| Padding | `0` on the inner iframe wrapper div (padding is on the card, not the iframe itself — override `.project-card` padding to 0 for the map container to avoid iframe offset) | Implementation detail |

**iframe attributes:**
- `src`: Google Maps embed URL for Manhattan (zoom 13), e.g. `https://www.google.com/maps/embed?pb=...`
- `width`: `"100%"`
- `height`: `"350"` (px, matches square at desktop)
- `style`: `border: 0` (removes default iframe border)
- `loading`: `"lazy"` (good practice; no functional impact)
- `allowFullScreen`: include
- `referrerPolicy`: `"no-referrer-when-downgrade"`
- No API key required — standard embed URL only

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Scroll into view | `ScrollReveal` wrapper triggers `.visible` class — fade + translate-up animation on map container. Same pattern as all other sections. |
| Map container hover | Border transitions to `var(--color-accent)`, background transitions to `var(--color-accent-glow)`. 0.2s ease (via `.project-card:hover`). |
| Map interaction | Standard Google Maps iframe interactions (pan, zoom, click POIs). No custom JS overrides. |
| Link hover (existing) | `color: var(--color-accent)`, `border-color: var(--color-accent)`. 0.2s ease (via `.link:hover`). Unchanged. |
