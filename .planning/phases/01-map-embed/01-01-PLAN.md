<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page.tsx → google.com | Cross-origin iframe loads untrusted content from an external domain |
| User browser → page.tsx | Static HTML/CSS delivered over HTTPS; no user input in this phase |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | `<iframe src>` | mitigate | Use only the canonical `https://www.google.com/maps/embed?pb=` URL (HTTPS). Never use HTTP. The pb= URL is sourced directly from Google Maps UI — no third-party domain substitution. |
| T-01-02 | Information Disclosure | `referrerPolicy` on iframe | mitigate | Set `referrerPolicy="no-referrer-when-downgrade"` on the iframe element. This is the Google-recommended value: sends origin on HTTPS→HTTPS, withholds on HTTPS→HTTP. Prevents full URL leakage to degraded endpoints. |
| T-01-03 | Tampering | Static markup in page.tsx | accept | page.tsx is a Server Component rendered at build time. No dynamic user input is injected into the iframe src. The pb= URL is a hardcoded string literal — no injection surface exists. |
| T-01-04 | Denial of Service | External iframe load | accept | Map load failure (Google outage, network block) is silent — iframe renders a blank tile area. No fallback needed; this is a non-critical enhancement. Low value target. |
| T-01-05 | Elevation of Privilege | `allowFullScreen` on iframe | accept | allowFullScreen only exposes Google Maps' own fullscreen UI — no privilege escalation beyond standard browser fullscreen API. Google Maps is a trusted, well-audited origin. |
</threat_model>
