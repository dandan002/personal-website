# Roadmap: Personal Website — v1.0 Google Maps Embed Integration

## Overview

A single focused delivery: embed a Google Maps iframe of NYC into the existing food section, sized responsively and styled to match the site's dark theme. All three requirements land in one phase — there are no meaningful delivery boundaries to split across.

## Phases

**Phase Numbering:**
- Integer phases (1, 2, 3): Planned milestone work
- Decimal phases (2.1, 2.2): Urgent insertions (marked with INSERTED)

Decimal phases appear between their surrounding integers in numeric order.

- [ ] **Phase 1: Map Embed** - Add a responsive, dark-themed Google Maps iframe to the food section

## Phase Details

### Phase 1: Map Embed
**Goal**: Visitors can see a working Google Maps embed of NYC inside the food section that looks native to the site
**Depends on**: Nothing (first phase)
**Requirements**: MAP-01, MAP-02, MAP-03
**Success Criteria** (what must be TRUE):
  1. Visitor sees a Google Maps iframe showing NYC when scrolling to the food section
  2. The map resizes correctly on mobile, tablet, and desktop without overflow or clipping
  3. The map embed visually fits the dark food section — no jarring white/light UI bleed
  4. The embed loads without requiring any API key or authentication
